# Форма

Локальный сервис для создания и публикации форм отклика и просмотра ответов студентов.

## Запуск

Требуется Node.js 20.19 или новее.

```sh
npm install
npm start
```

Откройте `http://localhost:3000/admin`. Чтобы изменить порт, задайте переменную `PORT`, например `PORT=3100 npm start`.

Для production-сборки выполните `npm run build`, затем запустите `NODE_ENV=production npm start`. Данные сохраняются в `data/forms.json`; файл создаётся автоматически при первом изменении и не перезаписывается при перезапуске.

## Возможности

- Создание нескольких форм, редактирование названия и описания.
- Вопросы с коротким и развёрнутым ответом, email, телефоном, выбором из списка и подтверждением.
- Настройка обязательности, вариантов списка и порядка вопросов.
- Публикация и снятие с публикации по отдельной ссылке `/f/<id>`.
- Проверка ответов и просмотр полученных анкет в панели по адресу `/admin`.
- Локальная JSON-база, без внешнего API и отдельной СУБД.

Все данные хранятся на компьютере, где запущен сервис.
